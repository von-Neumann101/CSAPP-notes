## Code Injection Attacks
![[Pasted image 20260608102602.png|559]]
利用缓冲区溢出，我们可以精确地修改返回地址，使得这个地址就是我们想要让被攻击者执行的代码。比如，本来在Q函数ret的时候，程序应该回到调用Q的下一句，但是实际上这个地址被黑客修改为了窃取信息的某个函数。
## Solution
- 不使用不安全的函数：
使用`fgets(buf, 4, stdin)`，它会截断超过4个字符的字符串；`scanf`的格式字符串不用`%s`而是`%ns`以指定最大输入的字符串长度
- 栈随机化(ASLR)
地址空间布局随机化：每次程序运行的时候，其地址是变化的。堆和栈都是随机的
![[Pasted image 20260608203223.png|400]]
- 可读、可执行分开
就算在栈里面加入一段恶意代码，并且通过修改地址使得CPU执行的语句跳转到该位置，由于现代系统通常把**栈标记为不可执行**，这一段注入代码依旧不被执行
- Stack Canaries（金丝雀）
![[Pasted image 20260608204254.png]]
这里40073c中加入`0x8(%rsp)`的值是一个特殊寄存器`%fs`提供的（从一个无法通过其他手段访问的内存中取一个值）金丝雀值
![[Pasted image 20260608204639.png|126]]
如果金丝雀值被修改了，后面会有一个条件判断，导致程序报错——金丝雀方法也是唯一无法破解的方法，上面的两种都可以破解
## Return-Oriented Programming Attacks
全局变量和代码本身的位置没有变，如果我们找到代码的位置，我们可以在那段代码里面注入我们的恶意代码。
