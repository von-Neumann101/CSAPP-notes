# 运算
## Unsigned Addition
$$\mathrm{UAdd}_w(u,v)=u+v\mod 2^w$$
```
13(10) + 5(10) 
-> 1101(2) + 0101(2) = 10010(2) 
-> 0010(2) = 2(10) = 13 + 5 mod 2^4
```
## Signed Addition
完全一样
```
-3 + 5
-> 1101 + 0101 = 10010
-> 0010 = 2 = -3 + 5
```
主要是因为bit溢出了（超过了w位bits表示的范围）
## Unsigned Multiplication
乘法的位数需要翻倍
```
5 x 5 = 25
0101 x 0101 = 00011001
-> 1001 = 9
```
由于我们截断超过w位的bits，所以仍然mod $2^w$

## Signed Multiplication
```
5 x 4 = 20
0101 x 0100 = 00010100
-> 0100 = 4

5 x 5 = 25
0101 x 0101 = 00011001
-> 1001 = -7
```
如果没有溢出，这是对的
```
-3 x -2 = 6
1101 x 1010 = 0110
-> 0110 = 6
```
## 乘以2的幂
`u * 2^k <==> u << k`
这是显然的（使用十进制的二进制展开即可）
移位会比乘法更快3倍
## 除以2的幂
移位比除法快30倍
对于除以2的幂，可以用移位
```
6 / 2 = 3
0110 >> 2 = 0011 = 3

3 / 2 = 1
0011 >> 2 = 0001 = 1
```
对于负数(Signed)，使用算术右移
```
-6 / 2 = -3
0110 >> 2 = 1101 = -3

-3 / 2 = -1
1101 >> 2 = 1111 = -1
```
一般编译器会增加一个偏置，然后使用右移（避免除法）
## 取反
补码+1
`x -> -x`
补码：翻转每一位：1变0, 0变1
```
-(6) = -6
0110 -> 1001 -> 1010 = -6
     补      +1
```
## 总结
可以使用的一个技巧，使用unsigned
```c
size_t i; // 可以用unsigned i;
for (i = cnt-2; i < cnt; i--)
    a[i] += a[i+1];
```
溢出产生时极其难以发现！
# Representation in memory, pointers, strings
64位机器，用64位bits表示地址（**实际上，允许使用的最大地址为47位**）
操作系统只允许在该内存的某些区域被引用，访问其他区域会产生“段错误”
## Machine Words
任何的计算机都有——“Word Size”（字长），其没有固定的含义。粗略地说，字长指的是在某种语言表示指针大小的最大数字或范围（从硬件上说，指的是有标准支持以储存或进行算术运算等操作的最大数据块）

# 习题
```c
int x = foo();
int y = bar();
unsigned ux = x;
unsigned uy = y;
```
- `x < 0  =>  x*2 < 0`
正确的，我们可以取x为TMin
- `ux >= 0`
正确的
- `x & 7 == 7  =>  (x<<30) < 0`
正确的，显然x的最低三位为1，移位后最高两位为1
- `ux > -1`
错误的，-1会变为UMax
![[Pasted image 20260421154859.png|334]]
- `x > y  =>  -x < -y`
错误的，TMin=100...0000，取反+1以后还是TMin
-  `x <= 0  =>  -x >= 0`
TMin
- `x >= 0  =>  -x <= 0`
对的
- `(x|-x)>>31 == -1`
错的（唯一反例——0）
- `ux >> 3 == ux/8`
对的，这里右移是补0
