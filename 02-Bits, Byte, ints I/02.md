# Number Representation
$$B2U(X)=\sum_{i=0}^{w-1} x_i2^i$$
$$B2T(X)=-x_{w-1}2^{w-1}+\sum_{i=0}^{w-2} x_i2^i$$
无符号B2U
```
4   3   2   1   0
16  8   4   2   1
0   1   1   0   1 -> 8 + 4 + 1 = 13
```

```
 4   3   2   1   0
-16  8   4   2   1
 1   0   1   1   0 -> -16 + 4 + 2 = -10
```

## 类型转换
混合了无符号和有符号的数据，**有符号的数据会隐式转换为无符号**
在比较中尤为易错！
![[Pasted image 20260419111646.png]]
|TMin|=|TMax|+1——当你做绝对值函数的时候，abs(TMin)=TMin

**int会被转换为无符号类型**——在倒序遍历数组的时候，这么写
`for (unsigned int i = size - 1; i >=0; i++)`
当i减到0以后，再次i--，会出现下溢，从而i变为UMax(int)——死循环
`for (int i = size - 1; i - sizeof(char) >=0; i++)`依旧死循环，因为sizeof(char)是无符号1
