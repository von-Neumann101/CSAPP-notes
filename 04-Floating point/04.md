## 规格化(Normalized)值
***当exp不为全0或全1***
指数**E = Exp - bias**（注意Exp和exp不是一个东西）
Exp: 把exp转为10进制(无符号)
bias: $2^{k-1}-1$其中k是指数位的数量，比如对于单精度——2^8-1=127

> [!NOTE] 为什么不像我们表示整数一样表示浮点
> 如果exp一样，我们只需要比较frac即可（和整数一样的表示）
> 把这个东西想象为十进制的科学计数法就很好理解了

由于M是在1到2之间的，所以M一定为1.xxx...x$_2$
xxx...x: frac的位
```
Min -> frac = 00...0(M = 1.0)
Max -> frac = 11...1(M = 2 - eps)
```
**Example:**
15213 = 11101101101101$_2$=1.1101101101101$_2$ x 2^13
M = 1.1101101101101$_2$
frac = 111011011011010000000000$_2$
E = 13
bias = 127
Exp = 140 = 10001100$_2$
（仔细区分E，Exp，exp的区别）
![[Pasted image 20260423154930.png]]
$\mathrm{Exp}\in[0,255]$
$\mathrm{E}\in[-127,128]$
## 非规格化值
***当exp为全0***
E = 1 - bias
M不再以1作为首位，而是M=0.xxx...x$_2$
当frac全部为0，这个值就是0
frac不为全0，这就是一个和0很近的值（而且是等间距分布）
能表示的最小非零数(frac=000...001)为$2^{-23}\cdot 2^{-126}$，最大能表示(frac=111...11)$(1-\varepsilon)2^{-126}$
## 特殊值
exp=111...1
如果frac=000...0 -> 代表无穷大inf（当我们除以0会得到这个值）
如果frac!=000...0 -> NaN（当我们对-1开方会得到这个值）

## Round
![[Pasted image 20260423170359.png]]
第一种——直接把小数点后抹掉（向0舍去）
IEEE默认的是——把相邻整数区间分为两半，一半向下取整，一半向上取整
如果被截断部分 > 1/2 → 向上  
```
如果被截断部分 > 1/2 → 向上
如果 < 1/2 → 向下  
如果 = 1/2 → 看保留位最低位：  
偶 → 不动  
奇 → +1
```
**原因**：不存在平均值偏大或偏小的统计偏差（一组均匀分布的数据，50%向上取整50%向下取整）

# C的浮点
我们在有符号和无符号整数之间转换，我们没有改变数据本身，而是改变了解释数据的方式
但是如果我们从double/float -> int，这将直接截去小数部分
float变int——23位(frag)->32位，不会损失数值
double变int——52位->32位，舍去小数后，可能也无法放入int中
反过来也是一个道理
